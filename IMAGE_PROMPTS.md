# Image prompts for the designer

These 4 prompts are for re-generating the carousel images with **"Useless Report"** as the unifying main title, while keeping the distinct visual concept of each image. The carousel concept is:

> *Same product. Four ways to pitch it. Same truth.*

Each image stays as it is visually — only the title text and subtitle change.

---

## Carousel concept (shared across all 4 images)

**Brand identity:**
- Main title (always): **"Useless Report"** — sans-serif, white, very large, top-left or top-center
- Tagline / subtitle: changes per image (see below) — lighter weight, color accent
- Style: dark background (deep navy / black), tech aesthetic, neon/electric accents (cyan, green, purple), clean modern UI illustrations
- Mood: satirical-but-professional — playful illustration, serious craft
- Aspect ratio: keep current (looks like 16:9 or 2:1)

**Critical rule for the designer:**
> Keep every visual element from the original image. Only change the title bar and the subtitle text. Don't redesign the illustrations, the manager characters, the panels, the arrows, or the colors. The carousel works *because* each image keeps its distinct visual angle.

## Recommended carousel order

For best storytelling:

1. **Image 4** ("Useless Report" — clean intro, shows the 3-input → adapted-output flow)
2. **Image 2** (the watching boss — the *why*: managers who need visibility)
3. **Image 1** (Manager Whisperer adaptation — the *how*: 4 different output styles)
4. **Image 3** (Upward Compiler — the *what*: the technical pipeline)

This sequence: introduce → identify the pain → show the mechanism → reveal the engineering.
